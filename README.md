# Facebook Form

### Naloga – Facebook obrazec

## Opis projekta
Pri tej nalogi sem izdelala spletni obrazec po vzoru Facebooka. Namen naloge je bil izdelati pregledno spletno stran z uporabo HTML, CSS in JavaScript.

## Uporabljene tehnologije
- **HTML** – struktura spletne strani in obrazca.
- **CSS** – oblikovanje in postavitev elementov.
- **JavaScript** – funkcionalnost in interaktivnost obrazca.

## Struktura projekta
- `HTML/` – HTML datoteke.
- `CSS/` – oblikovanje spletne strani.
- `JavaScript/` – JavaScript koda.
- `Slike/` – slike, uporabljene v projektu.
